Starlite Host Privacy Policy

Effective: August 20, 2026

Starlite Host turns a supported Android device into a local-network game streaming host. This policy explains what data the app processes and how it is handled.

Data processed for streaming

When you explicitly start screen capture, Starlite Host processes the device screen as video and may process device playback audio. This content is transmitted directly over your local network to the compatible client that you pair and choose to use. Screen video and device audio are processed in memory only for the active streaming session. Starlite Host does not save this content or send it to a developer-operated server.

Pairing information

Starlite Host stores a paired client's certificate or identifier locally on the Android device so the client can reconnect. App preferences are also stored locally. This information is not used for advertising or analytics and is not sent to a developer-operated server.

Sharing, advertising, and analytics

Starlite Host does not sell user data, share it with advertising companies, display ads, or include developer analytics. The app has no Starlite account system.

Network security

Starlite Host is designed for a trusted private local network. Pairing and some protocol channels use cryptographic protection, but the current video transport is not fully end-to-end encrypted. Do not use the app on an untrusted or public network.

Deleting local data

Screen and audio data are discarded when the live session ends. You can remove saved pairing information by unpairing clients, clearing Starlite Host's app data in Android settings, or uninstalling the app.

Children

Starlite Host is intended for users aged 13 and older and is not directed to children under 13.

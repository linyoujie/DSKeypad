DS Keypad Root Tools

AYANEO Pocket DS root helper files for DS Key Lab. These files are experimental and are not part of the Google Play version.

Disclaimer

Rooting can fail, boot-loop the device, erase data, or void warranty. Use these files only if you understand the risk and can recover the device. You are responsible for any result from running the scripts.

Downloads

Download Magisk v29.0 APK Download install.sh Download magisk29.tgz Download SHA256SUMS

Install With AYA Settings

Download and install Magisk v29.0.

Download install.sh to the device, then open AyaSetting -> Device -> Root Script and run install.sh.

Shell Option

Download files only:

curl -L https://linyoujie.github.io/DSKeypad/root/install.sh | sh

Download and flash root:

curl -L https://linyoujie.github.io/DSKeypad/root/install.sh | FLASH_ROOT=1 AUTO_REBOOT=1 sh

Additional files: root-install.sh.

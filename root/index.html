DS Keypad Root Tools

Experimental AYANEO Pocket DS root helper files for DS Key Lab. These tools are not part of the Google Play version.

Download only

curl -L https://linyoujie.github.io/DSKeypad/root/install.sh | sh

Download and flash root

curl -L https://linyoujie.github.io/DSKeypad/root/install.sh | FLASH_ROOT=1 AUTO_REBOOT=1 sh

If you use a custom domain, replace the URL or run with ROOT_BASE_URL=https://your-domain/root.

Files: install.sh, root-install.sh, SHA256SUMS.
